# Native Capacitor & PWA Integration — ErogaAI SaaS

## Capacitor Plugins Installed & Configured

- `@capacitor/core` & `@capacitor/cli`
- `@capacitor/camera`: Native camera capture with PWA fallback.
- `@capacitor/filesystem`: File saving for downloaded 606 TXT and PDF reports.
- `@capacitor/share`: Native sharing sheet for vouchers and reports.
- `@capacitor/haptics`: Tactile feedback on scan completion.
- `@capacitor/status-bar`: Dark/Light status bar styling.
- `@capacitor/splash-screen`: Native splash screen.

## Android / iOS Build Script
```bash
npx cap add android
npx cap copy android
npx cap open android
```

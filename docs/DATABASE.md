# Database Schema & Multi-Tenant Architecture — ErogaAI SaaS

## Overview

ErogaAI SaaS uses **Prisma ORM** with **SQLite** (development) and **PostgreSQL** (production) for 100% persistent data storage.

## Multi-Tenant Isolation Rule

Every business model contains a `organization_id` foreign key. All queries generated by the server enforce:
```sql
WHERE organization_id = $auth_user_organization_id
```
This guarantees 100% data isolation between tenant organizations.

## Core Models (25 Domain Tables)

1. `organizations`: Tenant accounts.
2. `companies`: Emitting legal entities and RNCs.
3. `branches`: Physical operational offices/sedes.
4. `users`: Team members.
5. `memberships`: User-organization role bindings.
6. `sessions`: Active HttpOnly session tokens.
7. `roles`: Custom and system RBAC definitions.
8. `permissions`: Granular system actions catalog.
9. `role_permissions`: Many-to-many permission bindings.
10. `expenses`: Expense records and DGII vouchers.
11. `expense_items`: Detailed invoice line items.
12. `expense_categories`: Accounting ledger categories.
13. `cost_centers`: Cost center budgets.
14. `suppliers`: Vendor RNC catalog.
15. `projects`: Project code cost tracking.
16. `vehicles`: Fleet fuel and mileage tracking.
17. `receipts`: Processed image files metadata.
18. `ai_provider_configs`: BYOK AI keys and models.
19. `ai_usage_logs`: Token consumption and latency history.
20. `api_keys`: External API keys with scopes.
21. `api_key_logs`: Inbound API HTTP request logs.
22. `webhook_subscriptions`: Outbound webhook events.
23. `audit_logs`: Immutable append-only audit trail.
24. `erp_configs`: AllSender ERP sync settings.
25. `erp_sync_jobs`: Idempotent batch ERP sync jobs.
26. `email_settings`: SMTP credentials.
27. `report_schedules`: Automated email report cron schedules.
28. `report_runs`: Email execution logs.
